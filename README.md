# 🧭 Гид по городам

Яркий информационный мини-сайт: выбираешь город → направление (с детьми / взрослым) →
категорию (рестораны / развлечения) и получаешь 5 мест с адресом, средним чеком и
коротким описанием.

**Сайт:** https://fdl0303-rgb.github.io/gid-po-gorodam/

## Что внутри

| Файл | Назначение |
|------|------------|
| `index.html` | Разметка страницы: hero, города, места, о нас, контакты |
| `assets/styles.css` | Строгий минималистичный стиль: волосяные линии, моно-подписи, одна акцентная кнопка. Цвета и радиусы — в `:root` |
| `assets/data.js` | **База городов и мест.** Сюда добавляем новые города |
| `assets/app.js` | Логика: переключение города / направления / категории, счётчики, анимации |
| `.github/workflows/pages.yml` | Автодеплой на GitHub Pages при push в `main` |

### Дизайн-токены

| Токен | Значение | Где применяется |
|-------|----------|-----------------|
| `--paper` / `--surface` | `#f7f7f5` / `#ffffff` | фон секций и карточек |
| `--ink` | `#101012` | текст, активные состояния, заливка кнопок |
| `--muted` | `#6f6f78` | вторичный текст |
| `--line` / `--line-strong` | `#e3e3df` / `#cdcdc7` | разделители, рамки |
| `--accent` | `#2f3ce0` | акцент: hover, бейдж «Бонус», счётчики |
| `--radius` | `8px` | кнопки и карточки |

Шрифты: `Inter` (текст) + `JetBrains Mono` (подписи, индексы, цифры).
Иконки мест — эмодзи, но обесцвечены (`grayscale(1)`) и возвращают цвет при наведении,
чтобы не спорить с общей строгой сеткой.

### Травяной заголовок

Крупный текст (h1, заголовки секций, названия городов) помечен классом `.grass` и выглядит
как яркая пушистая трава:

- градиент от тёмно-зелёного к лаймовому + вертикальные штрихи — через `background-clip: text`;
- мягкое зелёное свечение — `text-shadow` (работает даже при прозрачном `color`);
- мохнатый неровный край — SVG-фильтры `#grassRough` (крупный h1, `scale: 6`) и
  `#grassFine` (заголовки секций и города, `scale: 2.6`) из инлайн-блока `<svg>` в `index.html`;
- если браузер не умеет `filter: url()`, фильтр просто отбрасывается — остаются градиент и свечение.

Чтобы сделать травяным другой крупный заголовок, достаточно добавить к нему класс `grass`.

## Как добавить новый город (до 50)

1. Откройте `assets/data.js`.
2. Скопируйте любой объект из массива `CITIES` (например, `lipetsk`).
3. Поменяйте:
   - `id` — латиницей, уникальный (`belgorod`, `kursk` …);
   - `name`, `emoji`, `tagline`, `facts` (3 факта), `about` (1–2 предложения);
   - `gradient` — 2 цвета для карточки (`['#ff2e88', '#ff8a3d']`).
4. Заполните `directions` → `kids` / `adults` → `food` / `fun` → `places` (по 5 мест).
   У каждого места: `name`, `emoji`, `address`, `price` (средний чек), `desc`, `tags`.
   Опционально `bonus: {...}` — одно дополнительное место, оно помечается бейджем «Бонус».
5. Сохраните и задеплойте — карточка города, счётчики и меню подхватятся сами.

Города сортируются в том порядке, в котором перечислены в `CITIES`.
Порядок направлений — `DIRECTION_ORDER`, порядок категорий — `CATEGORY_ORDER`
(по умолчанию сначала «Развлечения», затем «Рестораны»).

## Что заполнено как образец (поменять на своё)

- **Контакты** (`index.html`, секция `#contacts`) — телефон, Telegram, email, VK, адрес, часы.
- **О нас** (`index.html`, секция `#about`) — текст проекта и цифры в статистике.
- Чек и цены мест — ориентировочные, это демо-данные. Перед публикацией проверьте
  актуальность: у каждой карточки есть кнопка «Открыть на карте».

## Локальный запуск

Просто откройте `index.html` в браузере — сборка не нужна.
Чтобы проверить как на сервере:

```bash
python -m http.server 8000
```
